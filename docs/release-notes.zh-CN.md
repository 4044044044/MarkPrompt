# 🗓️ 版本说明

🌐 [English](release-notes.md) | **简体中文**

> `2026.11.01-i18n1` · 英语优先，也为更多语言留出入口。

## 🌐 语言与偏好

- 未配置的 GUI 与 CLI 会话默认使用英语。本版本仍只随附英语和简体中文。
- `/lang [code]` 列出或切换自动发现的语言。GUI 记住选择；独立 CLI 通过 `--config` 保存偏好。
- 语言资源拆为独立 Python 模块；缺少消息时回退英语，并校验译文占位符兼容性。
- 帮助、补全描述、状态、错误、确认与人类可读 CLI 提示使用所选语言。切换时保留草稿、搜索、导航和待确认事项。

## 📖 文档

默认 README 和公开教程改为英语，并链接中文版本。原有 `README.en.md` 地址保留为指向默认 README 的兼容入口。[语言扩展文档](localization.zh-CN.md) 说明语言模块、自动发现、回退、校验和打包方式。

命令名、别名、关键词、JSON 字段、协议值与错误代码保持稳定。原有截图、动画、原创示例图片和示例笔记中的小彩蛋保留。

## 🔨 打包

GUI 与 CLI 构建都需包含 `markprompt_core.localization` 及其自动发现的语言模块。[打包命令](../README.zh-CN.md#build) 会收集这些 Python 子模块，无需新增运行时依赖。本次以 Windows 为验收目标；其他平台仍需独立验证。
